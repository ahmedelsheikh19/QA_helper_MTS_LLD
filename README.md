# Traceability Generator

A desktop GUI tool that generates bidirectional traceability reports in HTML format.
It checks which requirements are covered or missing across two dimensions:

- **LLD Traceability** — Requirements vs. Low-Level Design (Simulink/DOORS)
- **UT Traceability** — Requirements vs. Unit Tests

Each report is an interactive HTML file you can open in any browser.

---

## Input Files

### `req.xlsx` — Requirements (both reports)
- Exported from **DOORS**
- Contains all requirements that must be traced to both LLD and MTS/UT
- Must have a column named `ID` or `Object Identifier`

### `upstream.xlsx` — LLD file (LLD report only)
- Generated by the **Simulink-to-DOORS** tool
- Contains Low-Level Design items mapped to requirements
- Must have a column named `REQ`

### `ut.xlsx` — Unit Test files (UT report only)
- One or more Unit Test Excel files (multiple supported)
- Each file can contain multiple sheets
- Requirements are marked by a cell containing `A_REQUIREMENT_LABEL`, with the requirement IDs in the cell immediately to its right
- **Formatting rule:** the value must end with a comma, contain no spaces, and no newlines
  - Example: `REQ_001,REQ_002,`

---

## How to Use

Launch the application (`gui.py` or the `.exe`), then select a report from the left sidebar.

### LLD Report

1. Under **Input Files**, select your `req.xlsx` and `upstream.xlsx`
2. Under **Output**, set the output file name/path (default: `traceability_report.html`)
3. Click **Generate LLD Report**
4. When done, you will be prompted to open the report in your browser

### UT Report

1. Under **Input Files**, select your `req.xlsx`
2. Click **Add** to add one or more UT files — click **Clear** to reset
3. Under **Output**, set the output file name/path (default: `ut_traceability_report.html`)
4. Click **Generate UT Report**
5. When done, you will be prompted to open the report in your browser

## Report Contents

### LLD Report
| Section | Description |
|---|---|
| Covered Requirements | Exist in both `req.xlsx` and `upstream.xlsx` |
| Missing in LLD | Defined in `req.xlsx` but not found in `upstream.xlsx` |
| Missing in Reqs File | Found in `upstream.xlsx` but not in `req.xlsx` |

### UT Report
| Section | Description |
|---|---|
| Covered in UT | Exist in both `req.xlsx` and the UT files |
| Missing in UT | Defined in `req.xlsx` but not covered by any UT file |
| Missing in Reqs File | Found in UT files but not in `req.xlsx` |
| Format Violations | UT cells that break the formatting rule |
